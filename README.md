# LUMI — демо інтернет-магазину дитячих товарів

Демонстраційний фронтенд магазину дитячого одягу, іграшок та аксесуарів.
Побудований так, щоб його можна було нарощувати: адмінка, оплата, локалізація
і CRM під'єднуються без переписування компонентів.

## Стек

- Next.js 15 (App Router, Turbopack)
- React 19, TypeScript
- Tailwind CSS 4 (токени в `src/app/globals.css`)
- Zustand + `persist` — кошик та обране
- Motion (framer-motion 12) — анімації, зокрема політ товару в кошик

## Запуск

```bash
npm install
npm run dev
```

## Що вже працює

- Головна: split-hero, три категорії, добірка сезону, редакційний блок
- Каталог `/catalog` з фільтром за розділом і сортуванням
- Категорії `/catalog/[category]` з фільтром за розміром
- Картка товару `/product/[slug]`: галерея, вибір кольору та розміру,
  акордеон з описом, схожі товари
- Кошик: drawer, лічильники, прогрес до безкоштовної доставки, `localStorage`
- Чекаут `/checkout` з валідацією форми (без бекенду — демо)
- Картка в списку: зміна фото при наведенні, свотчі кольорів, швидке
  додавання з вибором розміру (на мобільному — кнопка «+»)
- Мобільна сітка — два товари в ряд

## Архітектура даних

Весь контент лежить у `src/data/*.ts` і типізований у `src/types/product.ts`.
Компоненти ніколи не імпортують фікстури напряму — вони ходять через
`src/lib/api.ts`:

```ts
getProducts();
getProductsByCategory(slug);
getProductBySlug(slug);
getRelatedProducts(product);
getFeaturedProducts();
getCategories();
```

Усі функції вже асинхронні. Коли з'явиться Sanity (або будь-який інший CMS/CRM),
змінюється тільки тіло цих функцій — сторінки й компоненти лишаються як є.

Модель товару побудована навколо варіантів:

```
Product
 └── colors: ColorVariant[]      // id, назва, hex, свої фото
      └── sizes: SizeOption[]    // label + inStock
```

`kind: "apparel" | "toy"` розділяє товари з розмірами та без них. Рядок кошика
адресується ключем `productId:colorId:size`, тож один товар у двох кольорах —
дві окремі позиції.

## Що ще не підключено

- Адмінка / CMS — свідомо, за домовленістю
- Оплата та відправка замовлення (чекаут показує підтвердження локально)
- Пошук, обране як окрема сторінка, відгуки
- Мультимовність — зараз лише українська
